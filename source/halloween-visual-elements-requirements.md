# 万圣节图素库需求 v1.0

状态：已确认
目标：让人和 Agent 直接找到可转译的万圣节视觉图素，而不是阅读趋势报告或跳转外部网页。

## 1. 图素定义

每条记录必须先有真实可见的图像，属于以下一种：

- 公版作品的清晰关键帧、插图、版画、海报或器物照片；
- 从上述原图中裁出的单一主体、动作、轮廓、边框或纹样；
- 在来源允许范围内制作的透明底图素，且能回溯到原始作品与具体画面。

纯文字线索、TikTok 帖子、商品截图、趋势描述和外部链接不算图素。

## 2. 前台形态

- 不建立独立万圣节趋势页，不在主导航增加专题跳转。
- 图素统一进入现有 `画面`、`场景 / 题材`、`节日` 三个入口。
- 卡片首屏只展示图像、名称、年代、版权状态和核心标签。
- 来源、版权证据、趋势出处与避让项放在详情层，不占主浏览层。
- 搜索和筛选结果必须直接返回图像卡，不能返回纯链接卡或说明卡。

## 3. 分类维度

至少覆盖：

- 骷髅动作、骷髅乐队、死亡之舞；
- 白布幽灵、墓园亡灵、鬼屋面孔；
- 墓碑、棺材、壁龛、钟表、蜡烛；
- 南瓜灯、黑猫、蝙蝠、月亮、乌鸦；
- 女巫、扫帚、坩埚、魔法仪式；
- 恶魔、地狱火焰、怪诞变形；
- 哥特建筑、表现主义阴影、旧海报排版；
- 万圣节边框、徽章、重复纹样与单色印花结构。

同时标注可用构图：单主体、双主体、队列、徽章、边框、满版、中心胸花、背部主图。

## 4. 单条记录字段

- 稳定 `id`；
- 预览图与 Eagle item ID；
- 作品名、具体版本、作者或制作方、年代；
- 图素类型、主体、动作、构图、风格、色彩与使用场景；
- 版权路径、证据等级、来源 URL、核验日期；
- `可转译`：可借用的视觉机制；
- `避开`：后期造型、现代角色、商标、演员肖像和受保护组合；
- 原图哈希或等价去重依据。

## 5. 趋势信息的处理

- TikTok、商品页和现代影视只用于发现题材热度与构图机制。
- 趋势证据保留在后台源数据，不直接成为前台素材。
- 每条趋势必须反查到公版原图或开放馆藏图；找不到可核验图源时标记 `待复核`，不进入公开图素池。
- Disney、现代恐怖片角色及其他授权 IP 只记录避让机制，不展示为可用图素。

## 6. 验收标准

- 打开筛选结果即可看到图，不需要再跳转才能判断画面；
- 图片可解码、无失效、无假棋盘格，移动端不横向溢出；
- 每张图都能回读到作品、版本、来源和版权路径；
- 同图去重，裁切图保留父图关系；
- 人可以按图素快速选题，Agent 可以从 JSON 按主体、动作、构图和版权状态检索；
- 内容验收、技术验收和使用审批分开，公版状态不等于平台自动准入。
