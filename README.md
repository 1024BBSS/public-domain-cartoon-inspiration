# 公版卡通灵感在线版

给同事和 Agent 共用的静态视觉索引。页面按类型检索，卡片只保留图、作品、版本与版权路径；点开后查看可取方向、避开项和原始来源。

## 公开边界

- 收录：已确认的期限届满、未续期、公共领域、开放馆藏或 CC0 版本。
- 排除：`未续期待复核`、`公版线索 · 待复核`、仍受保护版本、Eagle 本地路径和内部证据附件。
- 公版结论属于具体作品和具体版本，不自动覆盖后期角色造型、现代修复、商标、演员肖像或平台规则。

## 人与 Agent 的入口

- 人：打开 `index.html`，搜索、筛选、分页浏览，点击卡片查看来源。
- Agent：读取 `data/catalog.json` 和 `manifest.json`；每条记录有稳定 `id`、相对图片路径、来源链接和版权路径。

## 更新

源资料更新后，在本机运行：

```bash
node tools/build.mjs
```

构建会从 Eagle 事实源读取图片、生成 960px WebP 预览、重建公开数据，并重新复制指定设计系统的 `tokens.css` 与 `components.css`。
